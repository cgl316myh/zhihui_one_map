储量计算方法与数据来源

安宁隆瑞混凝土有限责任公司采石场 · 智慧矿山一张图
对应文件：public/data/reserves.json · 计算模块：js/modules/reserves.js

单位：万吨 基准时点：2024-12-31 无 2025 年报前以此为台账基准

一、计算方法

1. 可采储量

可采储量 = 评估利用资源储量 × 设计回采率 × 采矿回采率
  • 评估利用资源储量：对应年报「保有资源量」（控制资源量）。
  • 设计回采率：本矿对齐年报「可信系数」，当前取 1.0。
  • 采矿回采率：对齐年报「回采率」，当前取 0.95（95%）。

与年报口径对应：可信储量 ≈ 保有资源量 × 可信系数(1) × 回采率(0.95)。

2. 剩余可采与服务天数

剩余可采 = 可采储量 − 累计已采出
预计剩余天数 = 剩余可采 ÷ 日均采出（日均 > 0 时）
服务年限（年）≈ 预计剩余天数 ÷ 365
  • 当前默认台账以 截止 2024-12-31 的保有/可信储量 为起点，累计已采出设为 0，故剩余可采 ≈ 可采储量 ≈ 年报可信储量。
  • 投产后请在「管理后台 → 储量参数」按生产台账更新「累计已采出」「日均采出」。
  • 服务年限低于预警阈值（默认 3 年）时，大屏给出提示。

3. 采区回采率

采区回采率 = 采区采出量 ÷ 采区动用储量
  • 默认用 2023、2024 年度采剥数据作为两个「采区」行（年报年度汇总，非空间采区边界）。

4. 全矿回采率（按产量加权）

全矿回采率 = Σ(采区回采率 × 采区采出量) ÷ Σ(采区采出量)

二、数据来源

官方报告

统计截止日：2024-12-31

  • 报告原始单位为千吨；系统统一换算为万吨（÷10）。
  • 坐标体系为 CGCS2000 投影，与 Leaflet 经纬度底图不同，储量模块不引用报告坐标。

辅助数据说明

  • 趋势 / 预测曲线：在可信储量附近做示意插值，便于大屏展示，非独立勘探成果。
  • 日采出日历：按 2024 年开采量分摊到各月中旬的示意值，标注「年报分摊示意」。
  • 完整快照与原始千吨对照见 reserves.json 中的 reportSnapshot、dataBasis 字段。

三、维护方式

  1. 默认值来自仓库内 public/data/reserves.json。
  2. 管理后台「储量参数」保存后写入浏览器本地 localStorage（键名 mine-one-map-reserves-v2），会覆盖文件默认值。
  3. 若大屏数字与文件不一致，可在后台点击「恢复默认」，或清除该本地键后刷新。
  4. 取得 2025 及以后年报后，应更新 reserves.json 并同步本说明中的对照表。
