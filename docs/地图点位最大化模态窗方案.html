地图点位单击 → 最大化模态窗

目标：把 Leaflet 地图气泡弹窗（bindPopup）改为几乎全屏的模态窗；内容与现网一致（环境 / 边坡 / 视频 / 生产）。本文仅方案，等你下令后再改代码。

现状：map.js bindPopup 参考：admin.js modal-mask 文档：docs/地图点位最大化模态窗方案.html

1. 现状

点位单击走 Leaflet m.bindPopup(...) + popupopen/popupclose，内容在地图锚点旁小卡片里渲染。
涉及：环境、边坡、视频、生产（static/js/modules/map.js）。样式在 dashboard.css 的 .popup-card / .leaflet-*-popup。
管理后台已有轻量模态（admin.css 的 .modal-mask / .modal），大屏可复用交互模式，但需单独做「最大化」样式，避免和后台表单模态混用视觉。

2. 目标交互（示意）

边坡监测点 · XXX✕
最大化内容区：指标列表 + 图表 / 视频播放器（原 popup-card 内容迁入）
  • 单击点位 → 打开遮罩 + 近全屏面板（建议占视口约 92%～96%，四边留边距）
  • 关闭：右上角 ✕、点遮罩、Esc
  • 打开新点时先关旧窗，保证同时只有一个模态
  • 视频：打开时挂载播放，关闭时 stopVideoPlayback；图表同理 dispose

3. HTML 结构方案（建议写在 index.html）

在大屏 index.html 的 <body> 末尾（#map 所在主布局外）增加唯一模态壳，避免每个点生成一套 DOM：

<!-- 地图点位详情：最大化模态（默认隐藏） -->
<div id="map-point-modal" class="map-point-modal" hidden aria-hidden="true">
  <div class="map-point-modal__mask" data-modal-dismiss></div>
  <div class="map-point-modal__panel" role="dialog" aria-modal="true"
       aria-labelledby="map-point-modal-title">
    <header class="map-point-modal__hd">
      <h3 id="map-point-modal-title">点位详情</h3>
      <button type="button" class="map-point-modal__close" data-modal-dismiss
              aria-label="关闭">×</button>
    </header>
    <div class="map-point-modal__bd" id="map-point-modal-body">
      <!-- 由 JS 填入原 popup-card 内容 -->
    </div>
  </div>
</div>

4. JS 改造要点（非 HTML，但必须配套）

项做法
取消 Leaflet 气泡 环境/边坡/视频/生产：去掉 bindPopup，改为 m.on('click', () => openMapPointModal(...))
打开 API 新增 openMapPointModal({ title, html, onOpen, onClose })：写 title、把 html 塞进 #map-point-modal-body、去 hidden、执行 onOpen（挂图表/视频）
关闭 API closeMapPointModal()：先 onClose 释放播放器/图表，再清空 body、加回 hidden
内容复用 继续用现有 .popup-card HTML 字符串，减少重写；仅容器从 leaflet-popup 换成模态 body
程序化定位 现有 m.openPopup() 处改为同样走 openMapPointModal

6. 范围确认（请你拍板后再开发）

  1. 哪些点？默认建议四类全改（环境 / 边坡 / 视频 / 生产）。若只要边坡+视频也可以。

7. 验收建议

  • 四类点单击均开大窗，标题正确，关闭后无残留遮罩

  • 边坡/环境：图表在大窗内可读，关闭无控制台报错
  • Esc / 遮罩 / ✕ 三种关闭方式可用
