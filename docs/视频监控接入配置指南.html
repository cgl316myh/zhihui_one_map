视频监控接入配置指南

智慧矿山一张图 · 管理后台 admin.html → 视频监控
数据表：cfg_video_platform（平台） + biz_video_camera（点位）
大屏接口：GET /api/video

海康摄像头不一定需要萤石开放平台。 内网部署推荐 HLS 直链 或 ZLMediaKit； 要上公网云、用手机 App 同一套账号时，才用 萤石云 EZOPEN。

一、三种接入方式对比

ezviz 萤石云

  • 需萤石开放平台 AppKey/AppSecret
  • 设备须绑定萤石账号
  • 每路填：序列号 + 通道号
  • 适合：多矿点、外网访问

hls HLS 直链

  • 不需要萤石
  • 每路填完整 m3u8 地址
  • 或平台填一个演示/回退地址
  • 适合：已有流媒体输出的地址

zlm ZLMediaKit

  • 不需要萤石
  • 平台填 ZLM 服务地址
  • 每路填流名 zlmStream
  • 适合：海康 RTSP → 内网转 HLS

二、内网典型架构（海康 + ZLM，推荐矿山）

海康 IPC ×4（192.168.1.64~67） │ RTSP 子码流 :554/Streaming/Channels/102 ▼ ZLMediaKit（192.168.1.100:8080） │ 拉流代理 → 输出 HLS ▼ Spring Boot /api/video │ 拼 hlsUrl = baseUrl/live/{流名}/hls.m3u8 ▼ 一张图大屏（hls.js 播放）

海康 RTSP 地址规则

含义URL 示例
第 1 路主码流rtsp://admin:密码@192.168.1.64:554/Streaming/Channels/101
第 1 路子码流（大屏推荐）rtsp://admin:密码@192.168.1.64:554/Streaming/Channels/102
接 NVR 第 2 通道子码流rtsp://admin:密码@192.168.1.10:554/Streaming/Channels/202

规律：通道号 × 100 + 1 = 主码流，+ 2 = 子码流。

三、管理后台怎么填（4 路摄像头完整示例）

以下假设矿区 4 路：大门、破碎、筛分、边坡。坐标为示例，请改成实际 GPS。

方式 A ZLMediaKit（4 路海康 RTSP 经 ZLM 转 HLS）

① 平台接入（保存一次）

后台字段填写值
启用视频接入☑ 勾选
接入方式ZLMediaKit（按流名拼 HLS）
ZLM 服务地址http://192.168.1.100:8080
ZLM API 密钥your_zlm_secret（可选，用于 REST 拉流）
AppKey / AppSecret留空
HLS 演示/回退地址可留空

② ZLM 侧：为 4 路添加 RTSP 拉流（示例 curl）

curl -X POST "http://192.168.1.100:8080/index/api/addStreamProxy" \
  -d "secret=your_zlm_secret" \
  -d "vhost=__defaultVhost__" \
  -d "app=live" \
  -d "stream=cam-gate" \
  -d "url=rtsp://admin:Hik123456@192.168.1.64:554/Streaming/Channels/102" \
  -d "enable_hls=1"

# 其余三路 stream 分别填：cam-crush / cam-screen / cam-slope
# url 对应 192.168.1.65 / .66 / .67

③ 摄像头点位表（4 行）

ZLM 模式下：序列号/通道留空；在表格 ZLM 流名 列填写（如 cam-gate）。系统按 {ZLM地址}/live/{流名}/hls.m3u8 拼播放地址。

  "provider": "zlm",
  "ezviz": { "appKey": "", "appSecret": "", "domain": "https://open.ys7.com", "playerTemplate": "simple", "staticPath": "" },

五、操作步骤 checklist

  1. 重启后端，确认 Flyway V4__video_platform 已执行
  2. 登录 http://127.0.0.1:8081/admin.html → 视频监控（页内可打开本指南）
  3. 选接入方式，填平台参数 → 保存平台配置
  4. （ZLM）在流媒体服务器添加 4 路 RTSP 拉流
  5. 在表格添加 4 行摄像头 → 保存摄像头列表
  6. 打开一张图，视频面板应出现 4 路画面

六、常见问题

现象原因处理
只显示 LIVE 占位、无画面未启用 / 未填 HLS 或 zlmStream检查「启用」与每路地址
HLS 黑屏m3u8 浏览器不可达用 VLC 测地址；检查 ZLM 是否拉流成功
萤石 10031Token 无设备权限设备未加到开放平台账号
