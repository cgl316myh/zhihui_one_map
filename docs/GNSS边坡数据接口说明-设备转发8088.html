GNSS 边坡数据接口说明

来源：http://47.110.40.155:8088/document（GNSS 设备转发程序） · 整理日期：2026-11-01 · 本文仅文档，未改业务代码
用途：从 GNSS 设备转发服务拉取边坡监测站位移/偏移量（相对基准站的 X/Y/H），供 MineOneMap 边坡模块联调或替换现有 BDLX 拉取。
根地址：http://47.110.40.155:8088
凭证保管：联调账号由业务方提供（见下文）。请勿把明文密码提交到公开仓库；生产环境建议放进 Server99 secrets 或环境变量。

1. 准备

  1. 管理员开通账户（用户名 + 密码）。
  2. 知道要拉取的设备 SN（本项目现网 SN 与边坡点一致，如 17625038476）。
  3. 密码在登录请求中必须做 Base64 编码（不是明文 JSON）。
  4. 后续业务接口请求头 token = 固定前缀 1234567 + 登录返回的 data.token。

3. 获取单个设备的 GNSS 偏移量

项说明
地址GET /api/relay-config/getPushDataList
完整 URL 示例http://47.110.40.155:8088/api/relay-config/getPushDataList?sn=17625038476&beginTimeStr=2026-11-01%2000:00:00&endTimeStr=2026-11-01%2020:00:00

Query 参数

参数名类型必填说明
snstring是设备 SN
beginTimeStr string 否 开始时间 yyyy-MM-dd HH:mm:ss；不填默认「当前时间前 1 小时」
endTimeStr string 否 结束时间 yyyy-MM-dd HH:mm:ss；不填默认「当前时间」

请求头

参数名必填说明
token 是 "1234567" + 登录返回的 token（字符串拼接，不是 Bearer） 
token: 1234567<登录返回的 data.token>

响应

data 为 PushEntity[] 数组。字段见第 5 节。

4. 获取所有设备的 GNSS 偏移量

项说明
地址GET /api/relay-config/getPushDataListMultiDevice
完整 URL 示例http://47.110.40.155:8088/api/relay-config/getPushDataListMultiDevice

Query 参数

参数名类型必填说明
beginTimeStr string 否 yyyy-MM-dd HH:mm:ss；默认当前时间前 1 小时
endTimeStr string 否 yyyy-MM-dd HH:mm:ss；默认当前时间

请求头

响应结构与「单个设备」一致（PushEntity[]）。

5. PushEntity 字段说明

官方文档字段 + 实测多出的字段一并列出：

字段类型说明
snstring设备 SN
deviceIdnumber/string设备在本系统中的 ID
namestring点位名称（实测有，如 LRCS25038476(堆石平台)）
baseXnumber/string相对基准站的 X 距离，单位 m
baseYnumber/string相对基准站的 Y 距离，单位 m
baseZnumber/string相对基准站的 H 距离，单位 m
dateTimestring解算时间 yyyy-MM-dd HH:mm:ss
lonfloat经度；文档称 -1 表示未填（实测可能为真实坐标字符串）
latfloat纬度；同上
heightfloat高程；同上
correctionX/Y/Znumber/string实测字段，校正量（接入时需再确认语义）
stationInfoId / trueMonitorId / property—实测附加字段
单位注意：本接口 baseX/baseY/baseZ 单位是 米 (m)。 现有 MineOneMap 边坡大屏/库表多用 毫米 (mm)。若后续接入，需统一换算（×1000）并确认符号约定。

7. 推荐调用流程

  1. 将明文密码做 UTF-8 → Base64。
  2. POST /api/user/login 取 data.token（缓存约 8 小时，临近过期再刷）。
  3. 组装请求头 token: 1234567{token}。
  4. 优先 GET /api/relay-config/getPushDataListMultiDevice 拉全量；或按 SN 调单设备接口补历史。
  5. 按 sn 映射到边坡点位；把 baseX/Y/Z（m）换算为系统内部位移字段后入库/展示。

PowerShell 联调片段

$base = 'http://47.110.40.155:8088'
$user = '15925118626'
$pwB64 = [Convert]::ToBase64String([Text.Encoding]::UTF8.GetBytes('228218494@qq.com'))
$login = Invoke-RestMethod -Method Post -Uri "$base/api/user/login" `
  -ContentType 'application/json' `
  -Body (@{ username=$user; password=$pwB64 } | ConvertTo-Json -Compress)
$tokenHeader = '1234567' + $login.data.token
$h = @{ token = $tokenHeader }
$data = Invoke-RestMethod -Method Get `
  -Uri "$base/api/relay-config/getPushDataListMultiDevice" -Headers $h
$data.data | Format-Table sn, name, baseX, baseY, baseZ, dateTime

curl 示例

# 1) 登录
curl -s -X POST "http://47.110.40.155:8088/api/user/login" \
  -H "Content-Type: application/json" \
  -d '{"username":"15925118626","password":"MjI4MjE4NDk0QHFxLmNvbQ=="}'

# 2) 拉全量（把 TOKEN 换成 1234567 + 上一步 data.token）
curl -s "http://47.110.40.155:8088/api/relay-config/getPushDataListMultiDevice" \
  -H "token: 1234567<TOKEN>"
