1. 原则

  • 以 Server99 实况为准：线上正在用的接入（边坡云 BDLX、环境云 FT、ZLM 视频）优先保留。
  • 先藏后删：后台 UI 可先隐藏/禁用；库表与种子文件在确认无回滚需求后再物理删除。
  • 演示与空数据分离：无真实业务的演示载荷（如生产工段）不出现在地图，后台也不应再鼓励编辑。
  • 配置单一真相源：避免「库表 cfg_*」与「static/seed 旧 JSON」双轨并存造成改了后台大屏仍读旧文件。
  • 密钥不下文档明文：本方案不记录密码/Token 原文。

  • 用户与审计：运维必需。
  • 时序保留策略（3 个月）+ DB 备份联动：运维必需，不在「冗余」之列。
